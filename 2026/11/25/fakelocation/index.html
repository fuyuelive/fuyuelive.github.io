Fake Location 虚拟定位神器 —— 安卓模拟定位安装与使用教程

发表于2026-11-25|更新于2026-11-25|工具
|总字数:2.2k|阅读时长:6分钟|浏览量:

写在前面

平时总有些场景会用到”虚拟定位”这件事：测试自己的 App 在不同城市的显示效果、某些应用限定地区才能用、拍照片想要别的位置信息、或者单纯想在地图上”瞬移”一下。

安卓上做这个的工具不少，但真正好用、稳定、功能又全的其实不多。Fake Location 是我用了挺久的一个，作者是 Lerist，从早期的 Xposed 模块做到现在独立 App，算是国内这块最成熟的作品之一。

这个版本是 1.2.0.2，下面把安装和用法整理一下。

软件信息

项目 值
应用名称 Fake Location
包名 com.lerist.fakelocation
当前版本 1.2.0.2（versionCode 413）
安装包大小 13.37 MB
支持系统 Android 5.0 及以上（minSdk 21）
目标版本 Android 10（targetSdk 29）
架构 仅 armeabi-v7a（32 位）
SHA256 175C8D515170B42BC27299C965AFA0FA8F3F4F93DAB7455CB87A14D3BA87258A

注意架构那一栏：只带 32 位 so 库。绝大多数手机都能装，但少数只支持 64 位的机型（部分新旗舰、部分模拟器）会装不上或装上闪退，这是正常现象，不是你下载的文件坏了。

核心功能一览

这软件最狠的地方是功能分成了两层：免 ROOT 能用的和需要 ROOT 的。大多数同类软件免 ROOT 只能改个位置，它免 ROOT 也能玩路线和摇杆。

功能 是否需要 ROOT 说明
位置模拟 ❌ 不需要 地图选点、搜索地点、直接输入经纬度
路线模拟 ❌ 不需要 规划起点终点，按步行/骑行/驾车自动移动，也能”飞”
摇杆模式 ❌ 不需要 悬浮窗摇杆实时控制移动方向
海拔模拟 ❌（专业版） 自定义海拔高度
全功能摇杆 ❌（专业版） 自定义摇杆速度、方向锁定
步频模拟 ✅ 需要 从系统底层模拟传感器，模拟步数与步行状态
WIFI 模拟 ✅ 需要 模拟当前连接的和能扫描到的 WiFi
基站模拟 ✅ 需要 模拟基站信息
独立模拟 ✅ 需要 对指定的单个或多个应用单独模拟
反检测 ✅ 需要 避免被某些应用/游戏识别出虚拟定位
ROOT 隐藏 ✅ 需要 对指定应用隐藏 ROOT
定制专属包 ❌ 不需要 定制独立签名的安装包，从根上规避检测

简单说：免 ROOT 就能满足 90% 的需求，想玩到”防检测”这个层次才需要 ROOT。

下载

⬇ 下载 Fake Location 1.2.0.2（13.37 MB）

安卓手机直接点上面这个链接下载即可。下载完如果提示”无法安装未知来源应用”，去手机设置里允许浏览器安装应用就行。

下载后可以核对一下文件大小是不是 13.37 MB，或者用文件管理器看 SHA256 是否匹配上表，确保文件完整。

安装教程

方法一：免 ROOT（推荐先试这个）

第一步：装 App

把下载好的 APK 装到手机上，打开后先别急着操作，会要求登录（手机号或邮箱 + 验证码），注册一下就好了。

第二步：开启开发者选项

进入手机的 设置 → 关于手机，连续点击 版本号 7 次，直到提示”您已处于开发者模式”。

第三步：指定模拟位置应用

回到 设置 → 系统 → 开发者选项，找到 选择模拟位置信息应用（有的系统叫”选取模拟位置的应用”），点进去选中 Fake Location。

这一步是关键，漏了就点”启动模拟”没反应。

第四步：给权限

回到 Fake Location，把 定位权限 和 悬浮窗权限 都授予。摇杆功能必须要悬浮窗权限，App 里会有”前往授权”的按钮直接跳转。

第五步：开始模拟

在地图上点选目标位置，或者搜索地名，确认后点 启动模拟 就生效了。

小技巧：启动模拟时 App 会提示”建议打开 GPS”，这是对的。模拟位置 + GPS 开启能显著提高成功率，尤其是在室内或基站信号弱的地方。

方法二：ROOT 模式

如果手机已经 ROOT（Magisk / KernelSU 都行），直接在 App 里授予 ROOT 权限，然后那些带 (ROOT) 标识的功能就全部亮起来了：

  • 独立模拟（只对某个 App 生效）
  • 步频模拟
  • WIFI 模拟 / 基站模拟
  • 反检测 / 增强反检测
  • ROOT 隐藏

ROOT 模式的优势在于模拟更”底层”——不依赖开发者选项的模拟位置接口，很多靠这个接口就能识破虚拟定位的应用，在 ROOT 模式下也能骗过去。

功能详解

位置模拟

最基础也最常用。三种选点方式：

  1. 地图点选 —— 拖地图到目标位置，点一下确认
  2. 搜索地点 —— 直接搜地名
  3. 输入坐标 —— 填经纬度，甚至能填海拔

选好位置后保存，会自动进历史记录，下次直接点历史位置就行，不用重新找。

路线模拟

这个功能是拿来做”移动轨迹”的。规划好起点和终点，选择 步行 / 骑行 / 驾车 三种模式之一，App 就会带着你的虚拟位置沿着路线自动移动。

它规划路线的时候可以手动拖拽中间的转折点，所以不只是两点直线，复杂的绕路也能做。

配合 ROOT 模式下的 步频模拟 用，效果更真实——位置在动的同时步数也在涨，这套组合是很多人做运动打卡类记录时用的方案。

摇杆

悬浮窗上会出现一个虚拟摇杆，你推摇杆，虚拟位置就跟着走，方向、速度都由你实时控制。

免费版可以用基础摇杆，专业版才有自定义摇杆速度、摇杆方向锁定这些。

专业版与定制专属包

App 采用免费 + 专业版模式，免费版覆盖基础功能，专业版解锁：

  • 海拔模拟
  • 全功能摇杆（自定义速度、方向锁定）
  • 更长的历史记录等

另外有个挺巧妙的功能叫 定制专属包：它可以根据你的账号生成一个独立签名的安装包，这个包本身就没带 Fake Location 的特征，所以不开反检测也不会被认出来。

这个功能对没 ROOT 的用户特别有用——反检测需要 ROOT，但定制专属包不需要。

入口在 设置 → 定制专属包。

常见问题

Q：装不上，提示”解析程序包时出现问题”

大概率是机型架构问题。这个 APK 只含 armeabi-v7a，如果你的手机是纯 64 位（只支持 arm64-v8a），或者你在 x86 模拟器上装，会装不上。换台普通手机试。

Q：点了”启动模拟”没反应

检查三件事，按顺序来：

  1. 开发者选项里的”选择模拟位置信息应用”有没有选中 Fake Location
  2. 定位权限给了没有
  3. 手机上有没有开着”高精度定位”

Q：模拟一会儿就跳回真实位置了

常见原因：

  • 开启了”在 NOROOT 模式下搜索 GPS 信号”——App 里有提示，这个选项在有真实 GPS 信号的环境下会被真位置”抢”回去，室外建议关掉
  • 有些系统有额外的定位纠偏（比如某些国产 ROM 的网络定位服务），可以试试开启 ROOT 模式下的基站模拟

Q：应用检测到我在用虚拟定位

免 ROOT 模式下没办法彻底规避——因为开发者选项的模拟位置接口本身就是可被检测的。要绕过检测要么用 ROOT 模式开反检测，要么用定制专属包。

Q：会不会有安全风险

这个 APK 请求的权限里包括读取手机状态、存储、悬浮窗等，属于这类工具的常规需求。建议只从可信来源获取安装包，并核对 SHA256。本文附带的文件已核对过哈希，见上方表格。

最后

Fake Location 算是这类工具里做得比较完整的：免 ROOT 部分已经够用，ROOT 之后的功能深度也够，更新节奏稳定。

用它做 App 测试、地图功能验证这些正事非常顺手；具体能用在哪些场景，各位自己发挥。
