家校通 —— 基于 Python 的学生班级管理系统

发表于2026-10-09|更新于2026-10-09|项目
|总字数:7.7k|阅读时长:36分钟|浏览量:

写在前面

这是我之前参加比赛时写的一个小项目 —— 家校通，一个用 Python + tkinter 做的学生班级管理系统。

当时做它的初衷很简单：班主任日常要处理的事务其实非常琐碎，点名、记请假、录成绩、课堂上随机抽人回答问题、分组讨论……这些事情分散在各个 Excel 表和纸质记录里，查一次数据要翻好几个文件。所以就想着把这些都塞进一个程序里，做成”双击就能用”的桌面软件。

代码写完、比赛交完之后它就一直在硬盘里躺着。最近整理文件翻出来，索性打包发布到博客上，一来给自己留个记录，二来如果刚好有做类似东西的同学，可以直接拿去改。

说明：程序里的学生数据是测试数据（张三、李四），不是真实学生信息。默认账号密码也写在下面了。

程序界面

程序启动后先是一个登录窗口：

登录进去是主界面，一共四个功能标签页。

学生信息管理

录入和管理学生名单，包括姓名、家长电话、住址。表格里会实时显示每个学生的请假状态、请假原因、请假到期时间等信息，底部还有班级总人数统计。

支持把名单导出成 Excel，也支持从 Excel 导入，所以批量建名单不用一个个手敲。

电话栏做了格式校验，填错了会直接弹窗提醒；重名的学生也会被拦下来。

请假管理

选中学生后填写请假原因和时长。时长支持天 / 小时 / 分钟三个粒度组合，比如”2 天 3 小时 30 分钟”。

这个功能我觉得最实用的一点是：程序会自动算出请假到期时间，并且定时检查 —— 请假时间一到，学生的请假状态会自动变回”否”。不用老师自己盯着时间手动销假。

成绩管理

按科目录成绩，每录入一科就自动重算该学生的总分、平均分，并按总分给学生排名。支持单个学生多科成绩的一次性录入和修改，也能一键”移除所有成绩”从头再来。

课堂活动

两个小工具，都是上课时能救场的：

  • 随机抽取 —— 一键抽 1 人 / 3 人 / 5 人回答问题。它会自动跳过正在请假的学生，所以不用担心抽到一个不在教室的人。
  • 随机分组 —— 输入每组人数，自动把全班随机打散分组，讨论课分组几秒钟搞定。

下载与使用

下载

两个文件都放在 GitHub Releases 上：

文件 说明 下载
jiaxiaotong.exe 免安装绿色版（约 81 MB），双击即用 点此下载
jiaxiaotong.py Python 源码（947 行），需装 pandas 点此下载

如果页面打不开、下载很慢，是 GitHub 在国内网络环境下的常见情况，挂个代理会快很多。

下载下来的文件名是 jiaxiaotong.exe，你可以随便改成 家校通.exe，不影响运行。

使用步骤

  1. 下载 jiaxiaotong.exe，放到一个单独的文件夹里（程序会在同级目录读写数据文件和日志，别丢在桌面上一堆文件里）。
  2. 双击运行。因为是 PyInstaller 单文件打包，首次启动需要解压，等几秒，杀毒软件如果弹窗拦截请放行 —— 这是打包程序的通病，不是病毒。
  3. 用默认账号登录：
    • 用户名：admin
    • 密码：123456
  4. 在”学生信息管理”页把学生名单加进去，或者点”导入信息”直接读 Excel。

数据存在哪

程序会在当前目录下自动生成两个文件，建议整个文件夹一起备份：

  • 信息.xlsx —— 所有学生数据（名单、请假、成绩）。程序每做一次改动就自动保存，不需要手动存盘。
  • student_management_日期.log —— 运行日志，程序会自动把它设为隐藏文件。

想换电脑用？把整个文件夹拷过去就行，数据跟着走。

几个技术上的注意点

如果你也是用 PyInstaller 打包带 pandas 的程序，这几个坑我踩过，列出来省你时间：

  1. 必须在目标系统上打包。PyInstaller 不做跨平台交叉编译，Windows 上打的包只能在 Windows 跑，而且低版本 Windows 打的包向上兼容较好，反过来容易出问题。
  2. pandas 会让体积暴涨。pandas + numpy 打进来就是几十 MB，我这个 81 MB 基本都是它俩贡献的。只是读写 Excel 的话，openpyxl 单独用会小非常多。
  3. 单文件模式启动慢是正常的。--onefile 每次启动都要把内容解压到临时目录，介意的话用 --onedir 模式，启动快但会是一个文件夹。
  4. --noconsole 会吞掉报错。打包成无控制台窗口后程序崩溃你看不到任何信息，调试阶段先用带控制台的版本跑通再改。
  5. 路径要用 sys._MEIPASS 处理。打包后资源的相对路径基准变了，如果程序要读取自带的数据文件，得区分”开发时”和”打包后”两种情况。

另外提一句，登录密码在源码里是做了 SHA-256 哈希的，但默认密码 123456 是硬编码的。这个程序定位是单机个人使用，没有服务端，所以无所谓；如果你要改成多人共用的版本，这块必须重新设计。
